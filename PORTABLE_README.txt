Si Market助手 - Windows 便携版

启动方式
1. 将完整 ZIP 解压到有写入权限的文件夹，例如桌面。
2. 双击 run_portable.bat。
3. 浏览器会打开本机应用。请保持启动窗口运行；关闭窗口会停止应用。

此版本已内置 Python 和项目依赖，不需要另外安装 Python，也不会在首次启动时下载 pip 依赖。
首次运行仍需要联网获取行情和财务数据；网络或公开数据源不可用时，在线数据功能可能受影响。
Si智能功能仍在开发准备中，当前尚未开放智能分析。

数据与隐私
- 本包不包含发布者的 SQLite 数据库、股票池、历史报告或密钥。
- 用户数据保存在解压目录下的 data 文件夹中。
- 升级版本前请先备份 data 文件夹；用新版本替换旧文件时不要覆盖或删除已有 data。
- 请勿从不可信来源下载或运行程序包。
